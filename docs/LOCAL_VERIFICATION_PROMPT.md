## 3. Sync verification: two devices + two users

2. Both **offline**: edit *different fields* of the same task on each; add the *same habit completion day* on both; add a mood entry for the *same day* on both; reorder the same list on both. Reconnect.
   - Expect: both field edits survive (per-column last-write-wins); exactly **one** completion row and **one** mood row for that day (check in Supabase, not just the UI); reorder = last write wins (documented trade-off), contiguous `sort_order`.
3. **RLS between users:** second account on one device sees none of the first user's data; try reading/writing the first user's row IDs with the second user's JWT through PostgREST and confirm `0` rows / `42501`.

6. Document results (a short table) in the PR. Add any new automated test that is feasible (e.g. a connector unit test with a fake PostgREST client).
